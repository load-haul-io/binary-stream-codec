# binary-stream-codec

Zero-copy streaming codec utilities for protocol buffers and packed struct arrays.

[![CI](https://github.com/placeholder/binary-stream-codec/actions/workflows/ci.yml/badge.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A lightweight, high-reliability Python utility package developed for cloud-native microservices and pipeline health processing.

## Quickstart
```bash
pip install -r requirements.txt
python binary_stream_codec/core.py
```

## Running Tests
```bash
python -m unittest discover tests
```
